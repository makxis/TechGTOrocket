# ВРО-1 / RocketBoard — бортовое ПО учебной водяной ракеты

Проект «Технологии космоса / Реактивное движение».

Бортовая программа для платы авионики на ATmega32U4: чтение датчиков,
автомат полёта, управление системой спасения, телеметрия на MicroSD и по
радиоканалу, плюс наземная программа приёма.

## Как прошить плату (Windows)

1. **Code → Download ZIP** на этой странице, или возьмите папку с флешки.
2. Распакуйте архив: правая кнопка мыши → **«Извлечь все…»**.
3. Подключите плату кабелем USB.
4. Запустите **`ПРОШИТЬ ПЛАТУ.bat`** и отвечайте на вопросы мастера.

Интернет и установка программ не нужны. Если что-то не получается —
[release/FLASHING.md](release/FLASHING.md).

Приём телеметрии с ракеты — **`НАЗЕМНАЯ СТАНЦИЯ.bat`** (нужен Python 3),
см. [ground/README.md](ground/README.md).

## Состояние

Стадия: **прошивка работает на железе, наборы A и C проверены на стенде**,
радиоканал проверен между двумя платами.

Установлено достоверно:

- Контроллер — ATmega32U4, перечисляется как Arduino Leonardo
  (`2341:8036`), в Linux это порт `/dev/ttyACM0`.
- Инерциальный модуль — **ICM-20948** на `0x68`. Расхождение с ТЗ,
  где предполагалась MPU9250; см. раздел 2 HARDWARE.md.
- Барометр — **BMP280** на `0x77`.
- Сервопривод SG90 подключён на D6, проверен через сервисный режим.
- Радиомодуль **HC-12 v2.6** (9600 бод, канал 001, режим FU3) проверен
  28.09.2026 на двух одинаковых платах: полётная прошивка `c_radio` на
  одной, приём на другой через наземную программу. Тестовый профиль
  полёта прогнан трижды: все события дошли, потери пакетов 0-0,5 %.
- **На стенде HC-12 стоят на мощности P3 (+5 dBm)** — модули лежат рядом.
  Перед полётом вернуть **P8** (+20 dBm), см. `tools/hc12_setup`.
- MicroSD на стенде физически нет.
- В собранном корпусе не остаётся места под провод USB, поэтому живую
  телеметрию оттуда снять нечем, пока нет карты или радио.
- Распиновка сверена со схемой `DevBoard_Std_A3.pdf`, пп. 47.2 и 47.5 ТЗ закрыты.

## Сборка

Для разработчиков. Нужен `arduino-cli` в `PATH`, установка и все
команды — в [docs/TOOLCHAIN.md](docs/TOOLCHAIN.md). Библиотеки ставить
не нужно, они лежат в `firmware/libraries/`.

```sh
cd firmware
./build.sh              # набор A
./build.sh d_full       # полный комплект
./build.sh all          # все наборы, с расходом памяти
./build.sh a_basic upload
./build.sh release      # обновить готовые прошивки для мастера
```

## Наборы железа

Состав платы выбирается при компиляции: одной прошивкой на все
конфигурации ATmega32U4 не обходится, места не хватает (подробности
в MEMORY.md). Полётный код при этом **общий для всех наборов** —
автомат полёта работает одинаково везде, как требует п. 27 ТЗ.

| Набор | Состав | Флеш | ОЗУ |
|---|---|---|---|
| `a_basic` | датчики + сервопривод | 71 % | 29 % |
| `c_radio` | + HC-12 | 83 % | 39 % |
| `b_sd` | + MicroSD | 91 % | 58 % |
| `d_full` | полный комплект | 97 % | 67 % |

Файлы наборов — `firmware/src/hw/`, по одному на конфигурацию из п. 27 ТЗ.

```
  FLASHING.md             инструкция
  bin/                    готовые прошивки .hex
  avrdude/windows/        программа прошивки
  windows/                мастер прошивки (wizard.ps1) и драйверы
docs/                   документация
tools/                  диагностические скетчи
  hw_probe/               скан шины I2C и чтение идентификаторов
  imu_id/                 полный дамп регистров инерциального модуля
  imu_live/               живые показания ICM-20948
  hc12_setup/             настройка HC-12 (мощность, параметры) и мост USB <-> радио
ground/                 наземная программа, пп. 24-25 ТЗ
  rocket_ground.py        приём телеметрии, с окном и без
  telemetry.py            разбор пакетов и учёт потерь
  fake_rocket.py          имитатор борта для проверки без железа
  test_telemetry.py       проверки разбора
  vendor/                 pyserial 3.5, чтобы не нужен был pip
firmware/
  firmware.ino            главный цикл, п. 48 ТЗ
  build.sh                сборка и заливка
  sketch.yaml             профили и версии библиотек
  libraries/              Servo 1.3.0 и SdFat 2.3.0, сборка берёт их отсюда
  src/
    hw_config.h           выбор набора железа
    hw/                   файлы наборов A, B, C, D
    config.h              настраиваемые параметры, п. 38 ТЗ
    pins.h                распиновка
    drivers/              драйверы датчиков, свои, без библиотек
    flight_state.*        автомат полёта, пп. 10-15 ТЗ
    recovery.*            система спасения
    sensors.*             калибровка и фильтрация
    telemetry.*           формирование записей
    sd_logger.*           журнал на карте
    radio.*               телеметрия через HC-12
    diagnostics.*         флаги, события, индикация
    strbuf.*              сборка строк без printf
    service.*             наземный сервисный режим, п. 40 ТЗ
    sim.*                 воспроизведение профиля полёта, п. 43 ТЗ
    dbg.h                 неблокирующий отладочный вывод
```

## Что дальше

1. Проверить мастер прошивки на Windows 10 и 11 и окно наземной
   программы с настоящим радио.
2. Подключить MicroSD, проверить наборы B и D.
3. Закрепить плату в корпусе и закрыть п. 47.4 — ориентацию осей.
4. Уточнить по первому полёту пороги: `BACKUP_DEPLOY_TIME_MS` и углы привода.
