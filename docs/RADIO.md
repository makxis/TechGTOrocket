# Радиоканал HC-12

Настройка модулей, проверка канала и то, что известно о его поведении.
Формат данных и команд: [PROTOCOL.md](PROTOCOL.md). Пункты 22–25, 45, 47.11–47.12 ТЗ.

**Нужно только поставить мощность?** `ПРОШИТЬ ПЛАТУ.bat` → «Настроить мощность
радиомодуля» (или режим «Прошивка» в станции, прошивка `hc12_setup`).

## Схема

```
      БОРТ (RocketBoard)                             ЗЕМЛЯ (компьютер)
 ┌────────────────────────┐   эфир 433 МГц    ┌──────────────────────────┐
 │ D1 (TX) ─► RXD ┐       │  9600 бод, канал 1 │ RXD ◄─ TX  ┐             │
 │ D0 (RX) ◄─ TXD ├ HC-12 ~~~~~~~~~~~~~~~~~~~~~~~~ HC-12 ├─ FT232RL ─► USB
 │ D7      ─► SET ┘ (P8) │   полудуплекс      │ 5V,GND     ┘             │
 └────────────────────────┘                    └──────────────────────────┘
   TX и RX перекрещиваются: TX одного на RX другого
```

| Параметр | Значение |
|---|---|
| Порт борта | `Serial1`: D0 (RX МК), D1 (TX МК), `SET` на D7 |
| Настройки | 9600 бод, канал 001, режим FU3 (`RADIO_BAUD` в `config.h`) |
| Мощность | **P8 = +20 dBm (100 мВт)**, полётная и рабочая (антенны подключены) |
| Канал | **полудуплексный**: модуль не слушает, пока передаёт |
| Память | мощность и настройки хранит сам модуль, переживают перепрошивку |

Полётная прошивка вывод `SET` не трогает. Все настройки только скетчем
`tools/hc12_setup` (`release/bin/vro1_hc12_setup.hex`).

## Настроить модуль

1. Залить `hc12_setup` в плату, открыть порт (115200), нажать `8`, затем `~`.
2. Ожидаемый ответ: `OK+B9600`, `OK+RC001`, **`OK+RP:+20dBm`**, `OK+FU3`.

| Клавиша | Что делает |
|---|---|
| `~` | показать параметры, мощность не менять |
| `1`…`8` | мощность P1…P8 |
| `p` | вкл/выкл тестовые пакеты 5 в секунду (в формате телеметрии) |
| остальное | уходит в эфир как есть |

Скетч при старте мощность **не меняет**, только показывает. Нет ответа на
`AT` значит: модуль не запитан, перепутаны RX/TX или не работает цепь `SET`.

<details><summary>AT-команды вручную</summary>

`SET` прижать к земле, команды без перевода строки: `AT`, `AT+RX` (все
параметры), `AT+Bxxxx` скорость, `AT+Cxxx` канал 001–127, `AT+FUx` режим,
`AT+Px` мощность 1–8, `AT+DEFAULT`. Меняете скорость, меняйте и `RADIO_BAUD`,
и `HC12_BAUD` в `hc12_setup.ino`, и скорость порта в станции.

Мощности: P1 −1 dBm, P2 +2, P3 +5, P4 +8, P5 +11, P6 +14, P7 +17, P8 +20.

</details>

## Проверить канал

Штатно: станция, режим **Боевой (радио)**, кружок зелёный, «потеряно» около 0,
испорчено редко. Одной платой: режим **Отладка (радио)** → «Прогон профиля»,
должны прийти все 6 событий. Из консоли:

```sh
python3 tools/radio_test.py --ground /dev/ttyUSB0 --ground-baud 9600 --duration 30        # только приём
python3 tools/radio_test.py --rocket /dev/ttyACM0 --ground /dev/ttyUSB0 --ground-baud 9600 # полёт целиком
```

Скрипт считает пакеты, потери и события, вердикт `PASS` только при **6 из 6**
событий и без испорченных строк. `--raw файл` сохраняет сырые байты.

## Что важно знать о поведении

| | |
|---|---|
| **Полудуплекс** | команда с земли иногда теряется в столкновении с телеметрией: станция повторяет её до подтверждения |
| **Буфер 64 байта** | `Serial1` пустеет ~1 байт/мс; пакет с событием вместе не влезает, повторы событий идут через 60 мс после пакета |
| **Потери** | разрыв номеров при `rdrop=0` в отладке: потерялось в эфире; при `rdrop>0` борт сам выбросил |
| **Привод мешает радио** | при движении привода передача рвётся (см. ниже); вероятная причина питание на общей шине +5 В, не доказано |

<details><summary>Результаты 29.09.2026: P8, антенны, привод</summary>

- Плата → плата, P8, 10 см, 30 с в каждую сторону: 150 из 150, потерь 0.
- Прогон профиля через FT232: события 6 из 6 при чистом канале; при работающем
  приводе порча строки в апогее, где раскрывается привод: в стресс-тесте
  (`tools/servo_radio_stress`) привод рывком давал 6,9 % потерь при насыщении
  канала и до 20 % при 5 пакетах/с, без привода 0,1 %. Расстояние (10 см или 3 м)
  на результат не влияло, плавный ход привода не помогал; разнесение передачи и
  движения по времени снижало потери до 2,8 %.
- Меры в прошивке: CRC на всех строках (порча не проходит за данные), события
  повторяются 3 раза. Аппаратно: конденсатор
  470–1000 мкФ на шине +5 В у привода и HC-12, отдельное питание привода.
- Приём команд бортом проверен: счётчик `rx=` в отладке показывает верные кадры.

</details>

## Перед полётом

1. `hc12_setup` в бортовую плату → `8` → `~`, убедиться в `+20dBm`. То же для наземного модуля.
2. Залить полётную прошивку (`c_radio`; для пуска с картой `d_full`, но в ней нет радиокоманд).
3. В станции убедиться в зелёной строке готовности.
