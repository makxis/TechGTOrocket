# Как прошить плату ракеты

Для прошивки нужен только компьютер с **Windows 10 или 11** и кабель USB.
Интернет не нужен, устанавливать ничего не нужно. Весь проект можно
носить на флешке.

---

## Прошивка за 4 шага

**Шаг 1. Скачайте проект.**
На странице проекта на GitHub нажмите зелёную кнопку **Code**, затем
**Download ZIP**. Или возьмите готовую папку с флешки.

**Шаг 2. Распакуйте архив.**
Нажмите на скачанный ZIP правой кнопкой мыши и выберите
**«Извлечь все…»**. Из нераспакованного архива мастер не запустится.

**Шаг 3. Подключите плату** к компьютеру кабелем USB.

**Шаг 4. Запустите `ПРОШИТЬ ПЛАТУ.bat`** двойным щелчком. Он лежит в
самой верхней папке проекта.

Дальше мастер сам задаёт вопросы. Отвечайте цифрой и нажимайте Enter:

```
Что нужно сделать?
   1 — Прошить плату для полёта
   2 — Настроить мощность радиомодуля HC-12
   3 — Проверить, что плата работает
   4 — Установить драйверы (нужно только на Windows 7 и 8 или для переходника FT232RL)
   5 — Выйти
```

Для обычной прошивки выберите **1**. Мастер спросит, что стоит на плате
(карта памяти, радиомодуль), сам выберет нужную прошивку, запишет её,
проверит плату и скажет, всё ли в порядке.

**Пока идёт прошивка, не отключайте кабель.**

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| Окно мигнуло и закрылось | Архив не распакован. Распакуйте (шаг 2) и запустите из распакованной папки |
| «Windows защитила ваш компьютер» | Нажмите «Подробнее», затем «Выполнить в любом случае» |
| «Плата не найдена» | Возьмите другой кабель: бывают кабели только для зарядки, без передачи данных. Попробуйте другой разъём USB |
| «Windows видит плату, но для неё нет драйвера» | Согласитесь установить драйвер. Нужны права администратора — позовите учителя |
| «Прошивка НЕ записалась» | Отключите и снова подключите плату, запустите мастер ещё раз |
| «Радиомодуль НЕ отвечает» | Отключите плату, проверьте, что HC-12 вставлен до конца и правильной стороной |
| «Не удалось открыть порт» | Закройте Arduino IDE и другие программы, которые работают с платой |

Если ничего не помогло — покажите руководителю файл
`vro1_flash_log.txt` из папки `%TEMP%` (введите `%TEMP%` в адресной
строке Проводника).

## Что значит светодиод на плате

| Как мигает | Что это значит |
|---|---|
| медленно, раз в 2 секунды | всё хорошо, плата готова к старту |
| раз в секунду | плата ждёт, пока её положат и перестанут трогать |
| очень часто, 5 раз в секунду | ошибка: чаще всего не отвечает датчик |
| 2 раза в секунду | полёт |
| 2-3 раза в секунду | посадка, маячок для поиска ракеты |

**После включения поставьте ракету на площадку и не трогайте её
10 секунд.** За это время плата запоминает высоту площадки: светодиод
перестанет мигать раз в секунду и замигает медленно. Если ракету взять
в руки или передвинуть, плата подождёт ещё — ничего страшного.

Старт плата ловит в любом случае, даже если её не успели положить.

---

## Перед полётом: радио на полную мощность

Если на плате есть радиомодуль HC-12, перед полётом он должен работать на
полной мощности. На столе его убавляют, и модуль это запоминает.

При прошивке «для полёта» мастер спросит, для чего готовим радио —
отвечайте **«к ПОЛЁТУ»**.

---

## Важно про питание

Сервопривод питается от той же линии, что и сама плата. Если воткнуть
его в работающую плату, она зависнет.

**Сервопривод подключать только к выключенной плате.**

## Для руководителя

### Какие бывают прошивки

| Файл в `bin/` | Что стоит на плате | Сообщения в USB |
|---|---|---|
| `vro1_a_basic.hex` | датчики + сервопривод | есть |
| `vro1_c_radio.hex` | + радиомодуль HC-12 | есть |
| `vro1_b_sd.hex` | + карта MicroSD | нет |
| `vro1_d_full.hex` | всё вместе | нет |
| `vro1_hc12_setup.hex` | программа настройки HC-12, не для полёта | есть |

Одной прошивки на все случаи нет: в 28 КБ памяти ATmega32U4 всё сразу не
помещается. Полётная логика во всех наборах одинаковая.

### Что лежит в комплекте

| Где | Что |
|---|---|
| `bin/` | готовые прошивки и `SHA256SUMS.txt` |
| `avrdude/windows/` | avrdude 8.0 из официального пакета Arduino |
| `windows/wizard.ps1` | сам мастер, запускается из `ПРОШИТЬ ПЛАТУ.bat` |
| `windows/drivers/` | подписанные драйверы Arduino (плата) и FTDI (переходник FT232RL), установщик dpinst |

В Windows 10 и 11 драйвер для платы встроенный и ставится сам. Драйверы
из комплекта нужны на Windows 7 и 8.1, а также для переходника FT232RL
на компьютере без интернета.

### Проверка платы вручную

Для наборов A и C: открыть COM-порт платы на скорости **115200** (PuTTY,
монитор порта Arduino IDE). Должны идти строки вида:

```
47433 READY h=-0.32 max=0.00 |a|=1.00 p=98553 rec=ARMED err=0x0 rdrop=0
```

Состояние `READY`, высота около нуля, модуль ускорения около 1,00 g,
система спасения взведена, ошибок нет.

Команды в том же окне, только в состоянии `READY`:

| Клавиша | Что делает |
|---|---|
| `?` | справка |
| `i` | сведения о железе |
| `s` | привод в безопасное положение |
| `d` | привод в положение раскрытия |
| `t` | цикл проверки привода |
| `0`…`9` | угол привода от 0 до 180 |
| `r` | **прогон полного полёта на модели** — сервопривод срабатывает по-настоящему |

### Linux и macOS

Мастера нет. Скрипт `flash.sh` использует системный `avrdude`:

```sh
./flash.sh a_basic                  # порт ищется сам
./flash.sh c_radio /dev/ttyACM1
```

### Как прошивка попадает в плату

У ATmega32U4 загрузчик не сидит в памяти постоянно. Чтобы в него
попасть, COM-порт платы открывают на скорости **1200 бод** и сразу
закрывают. Плата перезагружается и примерно на 8 секунд появляется под
**другим** номером порта — туда и пишет avrdude:

```
avrdude -C ..\avrdude\windows\etc\avrdude.conf -c avr109 -p atmega32u4 -P COM4 -b 57600 -D -U flash:w:vro1_a_basic.hex:i
```

Мастер делает это сам.

### Как обновить прошивки в комплекте

После правок в коде: `cd firmware && ./build.sh release`, затем
закоммитить `release/bin`. Подробности — `docs/TOOLCHAIN.md`.
