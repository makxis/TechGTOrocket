# Станция и отладка ВРО-1

Одна программа для земли: приём телеметрии по радио, отладка платы по
радио или по проводу, прошивка. Пишет журналы в CSV. Пункты 24, 25, 45 ТЗ.
Порядок работы оператора: [docs/OPERATOR.md](../docs/OPERATOR.md).

## Запуск

| Как | Что нужно |
|---|---|
| двойной щелчок по **`СТАНЦИЯ И ОТЛАДКА.bat`** в корне | Python 3.8+ (с tkinter, «Add python.exe to PATH») |
| `python vro_station.py` в этой папке | то же |
| `VRO1-Station.exe` | ничего, но его надо [собрать](#сборка-exe) |

`pyserial` лежит в проекте (`vendor/`), интернет не нужен. В Debian/Ubuntu для
окна нужен `sudo apt install python3-tk`.

Приёмник: HC-12 на переходнике **FT232RL** (провода крест-накрест):
`VCC–5V`, `GND–GND`, `HC-12 TX–FT232 RX`, `HC-12 RX–FT232 TX`.

## Четыре режима

| Режим | Порт и скорость | Для чего |
|---|---|---|
| **Боевой (радио)** | FT232, 9600 | приём на пуске: показания, график, итоги, кнопка «Открыть парашют» |
| **Отладка (радио)** | FT232, 9600 | то же плюс управление платой по радио (без провода, от батареи) |
| **Отладка (провод)** | плата по USB, 115200 | живые показания и управление приводом |
| **Прошивка** | плата по USB | залить готовую или свою `.hex` |

Первое, что видно: **строка готовности к пуску** (внизу справа, цветная),
плитки состояния, график высоты, журнал событий. Кнопки, которые борт в
текущем состоянии не примет, серые.

<details><summary>Что на экране (плитки, счётчики, график)</summary>

- Плитки: состояние, высота, максимум, давление, спасение, время борта, номер
  пакета; вторым рядом итоги: апогей и время до него, скорость сейчас, макс.
  скорость подъёма, скорость спуска на парашюте, макс. ускорение (оценка по
  высоте: в радиопакете ускорения нет, настоящее видно только по проводу),
  время и высота раскрытия, время полёта, батарея.
- Счётчики справа сверху: принято, потеряно (по разрывам номеров), повторов,
  испорчено (не сошлась CRC), пакетов в секунду, давность последнего.
- **График**: окна 1/5/10/30 мин и «Всё», «Очистить график», плавная
  прокрутка. Границу между графиком и журналом можно тянуть мышью.
- **Батарея** `9.31 В · 96 %` **за диодом** (вход стабилизатора: на клеммах
  на ~0,45 В больше). 0 % = 7,0 В; кнопка «Батарея = 100 %» запоминает текущее
  напряжение (принимает только 7,6–10,5 В) в `vro_settings.json`.
- Тема: «Светлая тема» / «Тёмная тема» (для солнца: чёрный жирный текст).
- «Снимок экрана (F12)» сохраняет окно в `logs/screenshot_*.png`.

</details>

<details><summary>Кнопки управления (отладка)</summary>

«Обнулить высоту», «Вернуть в READY», «Цикл: открыть → закрыть», «Прогон
профиля полёта», «Закрыть серву» (слева), «Открыть серву» (справа), углы
0–180° шаг 20°. По проводу ещё «Сведения о плате», «Справка», своя команда.
**«Открыть парашют»** есть только в боевом режиме. Что и когда борт
принимает: [docs/PROTOCOL.md](../docs/PROTOCOL.md).

</details>

## Журналы

Пишутся сами с момента подключения в `logs/` (после каждой строки на диск):
`radio_*.csv` или `debug_*.csv`, после полёта `summary_*.csv`, снимки `screenshot_*.png`.
Кодировка utf-8 с BOM (Excel открывает русский текст), разделитель запятая.

<details><summary>Колонка kind в CSV</summary>

| kind | Что это |
|---|---|
| `packet` | новый пакет (колонки: seq, time_ms, state, altitude_m, pressure_pa, recovery, error_flags, vbat_v) |
| `duplicate` | повтор уже принятого номера |
| `event` / `event_dup` | событие и его повтор |
| `ack` | подтверждение команды бортом |
| `bad` | испорчена в эфире (CRC) |
| `raw` | прочий текст |
| `debug` / `text` | отладочная строка платы / прочий вывод платы (только провод) |
| `command` | команда, ушедшая на борт |

</details>

## Прошивка из программы

Режим «Прошивка»: список готовых прошивок (`release/bin`) с описанием, что
внутри и когда брать, или своя `.hex`. Плата сама переводится в загрузчик,
пишется через avrdude (встроен для Windows). После заливки список портов
сбрасывается: **выберите порт заново**. Из консоли: `python3 vro_flash.py --list`.

## Сборка exe

Сборка только на Windows (PyInstaller): распаковать архив `release/vro1-station-build.zip`
(его делает `python3 tools/pack_station_zip.py`), запустить `build_exe.bat`,
получить `dist\VRO1-Station.exe` (прошивки и avrdude внутри, журналы пишутся
рядом с `.exe`). Или GitHub Actions: `.github/workflows/build-exe.yml`.

<details><summary>Без окна, проверки, старая станция</summary>

```sh
python3 vro_station.py --console --mode debug --port /dev/ttyACM0 --cmd "i,z,d,s"
python3 vro_station.py --console --mode radio --port /dev/ttyUSB0 --seconds 60
python3 vro_station.py --list
python3 -m unittest discover .          # все проверки, железо не нужно
```

`rocket_ground.py` и `НАЗЕМНАЯ СТАНЦИЯ.bat` это прежняя простая станция
(только приём, журнал `.txt`); от неё нужна лишь функция списка портов,
для работы берите `vro_station.py`. `fake_rocket.py` даёт имитатор борта для
проверки без железа (`--loss 0.2` теряет пятую часть пакетов). Программа
читает и файлы `FLTnnnn.CSV` с карты памяти.

</details>

<details><summary>Состав папки</summary>

| `vro_flash.py` | заливка прошивки |
| `vro_shot.py` | снимок окна в PNG |
| `test_*.py` | проверки, 120 штук |

</details>
